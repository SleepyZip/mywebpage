This is a **sample post** written in Obsidian. It's marked `draft: true`, so it shows up in local previews but never on the live site.

## What works

Regular Markdown works as usual: *italics*, **bold**, [links](https://trevordemelo.com), lists, tables, and code.

- ==Highlights== like this
- Links to other posts with wikilinks, like [[Hello World|this one]]
- Images pasted into the note (`![[screenshot.png]]`), which get copied over when you publish
- Private comments, which are stripped out before publishing%% (like this one)%%

> [!tip] Callouts work too
> Obsidian callouts render in Solarized colors: `note`, `tip`, `warning`, `danger`, `info`, `question`, and `quote`.

```powershell
Get-NetAdapter | Where-Object Status -eq "Up"
```
